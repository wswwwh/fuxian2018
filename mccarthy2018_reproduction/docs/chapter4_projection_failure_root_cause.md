## Decision boundary

The committed v1 panel-(d) holdout remains unchanged: `0/4`,
`paper_projection=fail`, and `paper_3d=false`. All thesis panels had historical
exposure, and this root-cause pass reads panel (d), so every comparison below is
**post-hoc development evidence**, not a second holdout and not a new paper-level
acceptance result.

The failed holdout rejects the complete locked projection pipeline. Static
anchors passing 16/16 makes a gross camera-orientation/bounds error unlikely,
but it does not by itself exclude panel/time mapping, mask extraction,
rasterization, or surface-renderer semantics. Source-torus/DG geometry is a
leading candidate, not a uniquely proven cause.

## Next experiments

### C4-HALO-12P40-SOURCE-FALSIFICATION

Freeze the candidate before generating new comparisons:

- `JC=3.1389`, `T0=12.397983401715157 d`, `N=21`;
- thesis source targets `Ay=41815 km`, `Az=35783 km`;
- keep the existing camera, epsilon, four snapshot times, branches, renderer,
  crops, masks, and thresholds unchanged;
- generate all four Fig. 4.3/4.4 state panels without reading red masks;
- rebuild the same physical member at a higher N and phase-align directions;
- only then run the already-exposed projection comparison, labelled post-hoc.

State-space gates:

- `abs(T0_days-12.40) <= 0.005`;
- `abs(Ay_km-41815) <= 50 km`, `abs(Az_km-35783) <= 50 km`;
- curve residual `<=1e-9`, Jacobi span `<=1e-6`;
- determinant error `<=5e-9`, eigenvalue relative imaginary part `<=1e-10`;
- unstable-ring relative dispersion `<=6e-2`;
- manifold Jacobi drift `<=1e-10`;
- after N refinement, `abs(delta lambda)/abs(lambda) <=1e-3`, phase-aligned
  principal angle `<=5 deg`, and normalized 3D snapshot HD95 `<=0.01`.

The development projection metrics retain the existing gates: Chamfer/D
`<=0.02`, F1 `>=0.70`, HD95/D `<=0.05`, and area ratio in `[0.67,1.50]`.
They cannot retroactively turn the v1 holdout into a blind pass.
